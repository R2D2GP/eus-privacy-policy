# Política de Privacidad — EUS (Repositorio Web para GitHub Pages)

Este repositorio contiene la **Política de Privacidad oficial** de la aplicación móvil **EUS — El Juego de Crear tu Propio Negocio**.

Está diseñada y estructurada en un archivo web (`index.html`) para cumplir rigurosamente con los requisitos de la consola de desarrollador de **Google Play Store**, la **Google Play Families Policy**, y las normativas internacionales de protección de menores (**COPPA** y **RGPD/GDPR**).

---

## 🌐 Enlace Público (GitHub Pages)

Una vez activado GitHub Pages en este repositorio, la política estará disponible públicamente en:
👉 **`https://R2D2GP.github.io/eus-privacy-policy/`**

---

## 📲 ¿Dónde colocar esta URL en Google Play Console?

1. Entra a tu consola de desarrollador en [Google Play Console](https://play.google.com/console).
2. Selecciona la aplicación **EUS**.
3. En el menú lateral izquierdo, ve a **Contenido de la app** (App content) ➔ **Política de privacidad** (Privacy policy).
4. Pega la URL: `https://R2D2GP.github.io/eus-privacy-policy/`
5. Guarda los cambios. ¡Listo!
